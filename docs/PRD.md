## 2. 产品概述

### 2.1 产品定位

一个**学生的个人数字花园 / 私人档案馆**，不是求职简历，也不是商业作品集。

- 视觉上是一本装订起来的旧档案册：牛皮纸纹理、打字机编号、活页打孔、盖章、手写批注。
- 内容上记录工程项目、手记随笔、生活碎片与自我介绍。
- 结构上是**前后台一体的个人站点**：访客浏览，所有者通过后台维护内容，无需改代码重新发布。

### 2.2 目标用户

| 角色 | 诉求 |
|---|---|
| 站点所有者（唯一管理员） | 通过浏览器后台维护个人信息、项目、手记；查看与清理访客留言 |
| 访客 | 浏览个人介绍、作品与生活记录；留下留言；在移动端正常阅读 |

### 2.3 核心价值

1. **内容可维护**：项目 / 手记 / 留言 / 个人信息均落库，后台即改即生效。
2. **风格统一**：前台与后台共用一套「牛皮纸 + 老派手稿」视觉语言，后台不是通用管理模板。
3. **轻量**：无重型 UI 框架，前端仅 React + Router + axios；数据库为单库 5 表。

### 2.4 成功标准

| 指标 | 目标 |
|---|---|
| 首屏可用 | 导航下方轮播图与 Hero 标题在 3s 内可见（本地资源、图片已压缩） |
| 生产构建 | `npm run build` 通过 TypeScript 严格模式，无类型错误 |
| 内容更新 | 后台保存后刷新前台即可看到变化，无需重新构建 |
| 移动端 | 390px 宽度下无横向滚动、轮播装饰不遮挡交互元素 |
| 可访问性 | 轮播可键盘操作，装饰层不拦截点击，减动效偏好生效 |

## 3. 信息架构与路由

### 3.1 前台（公开）

| 路由 | 页面 | 主要内容 | 数据来源 |
|---|---|---|---|
| `/` | 首页 | 全幅轮播 + Hero 介绍 + 肖像 + 随手卡片架 | 轮播本地图片；卡片部分读 `settings` |
| `/works` | 作品 | 工程档案列表 + 碎片与光影画廊 | `GET /api/projects`；`src/data/fragments.ts` |
| `/notes` | 介绍 | 手记目录 + 个人档案卡（双列错落） | `GET /api/posts`；`GET /api/settings` |
| `/guestbook` | 留言 | 明信片留言表单 + 便签墙 | `GET /api/messages`；`POST /api/guestbook` |
| `/about` | 关于 | 手写信 + 邮戳 + 常用工具 / 联系方式 | 前端静态常量 |
| `*` | 兜底 | 未匹配路径回到首页 | — |

导航项固定为：首页、作品、介绍、留言、关于。导航栏 `position: fixed`，高 64px，半透明毛玻璃；路由切换自动回到页面顶部。

### 3.2 后台（需登录）

| 路由 | 页面 | 能力 |
|---|---|---|
| `/admin` | 档案馆通行证登录 | 账号密码登录，签发 7 天 JWT |
| `/admin/dashboard` | 内容概览 | 项目 / 手记 / 留言数量统计 + 快捷入口 |
| `/admin/dashboard/profile` | 个人信息 | 基本信息、头像、关于我档案卡字段、首页卡片字段 |
| `/admin/dashboard/projects` | 项目管理 | 列表、新增、编辑、删除 |
| `/admin/dashboard/posts` | 博客管理 | 列表、新增、编辑、删除 |
| `/admin/dashboard/messages` | 留言管理 | 列表、删除 |

未登录访问 `/admin/dashboard/**` 由路由守卫重定向到 `/admin`；接口返回 401 时前端清除本地令牌并跳回登录页。

## 4. 前台功能需求

### 4.1 全局框架

- **背景**：固定牛皮纸实拍图（`public/paper-bg.png`）+ 径向暗角；图片加载失败时以 `#B29770` 兜底。
- **导航**：5 个路由链接，当前路由以复古红下划线高亮；毛玻璃底 `blur(8px)`。
- **页脚**：版权 + GitHub / X / Email 社交链接（当前为占位可替换）。
- **边缘装饰**（宽屏）：左右竖排 marginalia、四角印刷准星、左侧装订孔；全部 `pointer-events: none`。
- **水印**：`body::before/::after` 极淡 `+` 与 `◇` 几何符号（透明度 0.1）。
- **自定义光标**：仅桌面精确指针设备启用羽毛笔 / 齿轮 SVG；触屏回退系统指针。
- **减动效**：`prefers-reduced-motion: reduce` 下动画与过渡压至 0.01ms。

### 4.2 首页 Hero

| 元素 | 要求 |
|---|---|
| 刊号 | `EST. 2026 · VOL. 01`，打字机字体、宽字距、复古红 |
| 英文小标 | `MY INTRODUCTION TO THE WORLD · 2026` |
| 主标题 | `My Introduction`，Fraunces 衬线，`clamp(48px, 7vw, 88px)`，凸版微阴影 |
| 正文 | 一段自我介绍，首字下沉（复古红起笔） |
| 肖像 | 4:5 竖幅，椭圆双层描边相框，顶部卷草饰花，右上角火漆印章 `M`，轻微旋转 |
| 批注 | 照片下方 Caveat 手写体 `A collection of recent works.` |
| 水印 | 右上角巨型「园」字，透明度 0.06，不拦截交互 |

移动端（≤768px）：文字与肖像改为纵向排列，肖像居中、宽度 200px。

### 4.3 Hero 全幅轮播（核心模块）

**布局**

- 位置：紧贴固定导航下方，Hero 区域首位；外层无 margin / padding / border，导航下方直接是照片。
- 宽度：100%，无白色相纸边框。
- 高度：桌面 `clamp(320px, 42vh, 480px)`；≤768px 为 `clamp(240px, 36vh, 340px)`。
- 图片：`object-fit: cover`，三张本地 JPEG 各自指定 `object-position` 取景；显式 `width/height` 防止布局抖动。

**复古融合**

- 图片滤镜：`sepia(0.4) contrast(1.05) brightness(0.95)`。
- 纸色叠印：上层 `rgba(178,151,112,0.4)` + `mix-blend-mode: multiply`，让照片像印进牛皮纸。
  > 说明：由于内容层 `z-index: 10` 形成混合隔离，混合作用加在叠印层而非 `<img>` 上，视觉等效。
- 底边渐隐：图片下 50% 覆盖牛皮纸色线性渐变，最终 `rgba(220,203,173,0.96)`，使照片下沿溶入纸背景。
- 四周暗角：`box-shadow: inset 0 0 70px rgba(43,29,20,0.26)`。

**交互**

| 交互 | 规则 |
|---|---|
| 自动轮播 | 5s 切换；切页后重新计时 |
| 暂停条件 | 页面隐藏（visibilitychange）、键盘 `:focus-visible` 聚焦、`prefers-reduced-motion` |
| 左右箭头 | 固定于画幅左右边缘，线形箭头，细描边，hover 提亮 |
| 页码指示器 | 右下角 `01 / 02 / 03`，当前项复古红 + 实线下划线 |
| 键盘 | 聚焦轮播区后 `←` / `→` 切换 |
| 触摸 | 横向滑动，位移阈值 40px，决定上一张 / 下一张 |

**手工剪贴装饰层**（绝对定位，`aria-hidden`，`pointer-events:none`，不影响文档流）

1. **两侧胶带**：半透明白 `rgba(255,255,255,0.4)`，细斜纹微纹理，`clip-path` 毛边，左右分别倾斜 -4° / 3.5°，跨越画幅底边与纸面；≤768px 隐藏以避免挤压。
2. **打字机纸条**：居中，底色 `#fbf9f4`，下沿撕口，双层阴影，倾斜 -1.6°；内容 `FIG. 0N — ARCHIVE PLATE / SHOT ON FILM`，编号随当前页动态变化；纸条顶部压一小块半透明胶带。
3. **复古分割线**：两段向两端渐隐的细线 + 中央 `◇`，整体透明度 0.3；定位与 Hero 文字区上边距同步，始终位于文字区上方约 40px。

**可访问性**

- 轮播容器 `role="region"`、`aria-roledescription="carousel"`、`aria-label`。
- 非当前帧 `aria-hidden="true"`；页码按钮使用 `role="tab"` + `aria-selected`。
- 图片提供中文 `alt`；箭头按钮提供 `aria-label`。

### 4.4 首页随手卡片架（FillerCards）

| 卡片 | 内容 | 数据 |
|---|---|---|
| 时钟 | 时:分（秒字号更小）+ 日期，每秒刷新 | 客户端 `setInterval` |
| 摘录 | 一句引言 + 出处，Caveat 手写体 | `settings.excerpt_text / excerpt_from`，留空回退默认 |
| 月历 | 当月网格，今天以复古红底高亮 | 客户端计算 |
| 在读 | 书名 / 作者 / 进度 | `settings.reading_title / reading_author / reading_progress`，留空回退默认 |
| 天气 | 城市 + 温度 + 描述 | 静态占位，后续可接 API |

布局：3 列网格，摘录卡跨 2 列；每张卡带微旋转与打孔点；≤900px 两列，≤560px 单列。

### 4.5 作品页 — 工程档案（ProjectIndex）

- 标题区：`PROJECT INDEX · 工程档案` + 衬线大标题。
- 每条档案 = 活页索引卡：左侧 3 个打孔，双线边框，半透明纸底 + 毛玻璃。
- 内容：标题、描述、技术栈（逗号分隔 → ` · ` 连接）、右上角盖章标签 `CODE` / `HARDWARE`。
- 交互：hover 右移 4px，标题变复古红。
- 数据：`GET /api/projects`，失败显示错误提示，加载中显示占位文案。
- 超宽屏（≥1440px）左侧显示手写批注 `Keep exploring ↓`。

### 4.6 作品页 — 碎片与光影（FragmentGrid）

- 4 张生活碎片，数据来自 `src/data/fragments.ts`（含 4 个 `// PLACEHOLDER` 文案与 picsum 固定种子图）。
- Bento 网格：3 列，第 1 张跨 2 列（主海报卡），第 4 张跨 2 列；≤1024px 两列，≤640px 单列。
- 卡片：编号 `№ 00`、复古滤镜配图、标题、随想、关键词、右下角页码 `— P. 01 —`；主卡右上角 `ARCHIVE` 红印章。
- 互动：hover 上浮 + 标题下划线展开；进入视口时按序号每张延迟 60ms 淡入。

### 4.7 介绍页 — 手记目录（BlogList）

- 数据：`GET /api/posts`，按 id 倒序（新在前）。
- 每行：手绘 `✓`、打字机日期、衬线标题、右端 `→`。
- 点击行原地展开摘要（高度动画），箭头旋转 90°；再次点击收起；同一时间仅一行展开。
- 底部：`查看全部手记 →`（当前指向 `/notes`，属占位）+ 一张风景照 `figure`（picsum 占位）。

### 4.8 介绍页 — 个人档案卡（AboutMeCard）

- 外观：档案夹索引标签页 + 双线边框 + 打字机登记行。
- 字段：AGE / LOC / MAJOR / HOBBY；荣誉与证书列表（名称 + 年份盖章样式）；个人简介。
- 数据：`GET /api/settings`；简介优先取 `bio`，为空时回退 `monologue`。
- 状态：加载中文案、失败提示、空字段显示 `—`。

### 4.9 留言页（Guestbook）

- 表单：昵称（≤20 字）、留言（≤200 字），提交按钮文案「盖上邮戳 / 正在投递」。
- 服务端限制：昵称与内容非空、内容 ≤500 字；客户端另有 maxLength 约束。
- 提交成功后清空表单并重新拉取列表。
- 便签墙：每条留言为微旋转便签（±1~2°），显示内容、署名、时间（`YYYY.MM.DD HH:mm`）。
- 状态：加载中、读取失败、空信箱均有对应提示。
- 安全：留言内容以 React 文本节点渲染，不做 HTML 注入。

### 4.10 关于页（AboutSection）

- 手写信版式，微倾 -0.4°；右上角邮票（picsum 占位）与圆形邮戳（波浪线 + DALIAN + 日期）。
- 正文三段自我介绍 + Caveat 手写签名。
- 信纸下方：常用工具标签（VS Code / Trae / IDEA / Git）与联系方式（Email / GitHub，占位）。

## 5. 后台功能需求

### 5.1 登录（`/admin`）

- 版式：档案馆通行证（票根打孔、ADMIN ONLY 圆章、持有人 / 有效期字段）。
- 输入：档案编号（用户名）、通行口令（密码）；均不可为空。
- 提交：`POST /api/login`；成功将 JWT 写入 `localStorage.admin_token` 并跳转 `/admin/dashboard`。
- 失败：展示后端错误（如「用户名或密码错误」）或网络错误提示。
- 附带「返回前台档案馆」链接。
- 令牌有效期 7 天；密码以 bcrypt 哈希存储。

### 5.2 路由守卫与退出

- 无令牌访问后台内页 → 重定向 `/admin`。
- 任意后台写操作返回 401 → 清除令牌、跳回登录页，并提示「登录已过期」。
- 侧栏「注销通行证」清除令牌并返回 `/admin`。

### 5.3 后台框架（AdminLayout）

- 左侧固定书脊侧栏（268px）：深褐底、装订边、竖排小字、5 项目录（编号 01–05）。
- 当前菜单项：复古红索引条 + 高亮底色；hover 右移 7px。
- 底部：返回前台、注销、`Admin Only · 2026`。
- ≤960px：侧栏变为顶部整块，主区取消左偏移。

### 5.4 内容概览（AdminDashboard）

- 统计卡：工程档案 / 手记随笔 / 访客留言数量（3 个接口并行读取）。
- 快捷归档：4 个入口跳转对应管理页。
- 馆员备忘卡片。
- 状态：加载中、读取失败提示。

### 5.5 个人信息（AdminProfile）

分为三组字段，保存时一次性 `PUT /api/settings`：

| 分组 | 字段 |
|---|---|
| 基本登记 | 姓名、职位、一句话介绍、邮箱、所在地区、个人简介、头像 |
| 关于我档案卡 | 年龄、专业、爱好、荣誉与证书（可增删的「名称 + 年份」列表） |
| 首页卡片 | 摘录内容、摘录出处、在读图书、作者、阅读进度 |

- 头像：可粘贴图片链接，或选择本地图片（≤2MB，JPG/PNG），前端转 Base64 存入 `avatar`（`MEDIUMTEXT`）；支持撤下。
- 右侧实时相纸框预览，显示姓名与 `FILE NO. A-01`。
- 保存成功提示「已归档 · 修改已写回馆藏，前台已同步」；失败展示后端/网络错误。
- 荣誉保存前自动去空格并丢弃空标题项。
- 字段说明：`bio` 同步到前台档案卡；`monologue` 为历史字段，后台不再提交，但服务端保留。

### 5.6 项目管理（AdminProjects）

- 表格列：编号、标题 + 描述、技术栈、分类、操作。
- 新增 / 编辑共用档案卡片弹窗：标题（必填）、分类（CODE / HARDWARE）、技术栈（逗号分隔）、描述。
- 删除需 `window.confirm` 二次确认；成功后刷新列表并提示编号。
- 空列表、加载中、读取失败均有提示。
- 弹窗支持 Esc 与点击遮罩关闭；保存中禁止关闭。

### 5.7 博客管理（AdminPosts）

- 表格列：编号、日期、标题 + 摘要、操作。
- 新增默认日期为当天 `YYYY.MM.DD`；日期与标题必填。
- 其余交互同项目管理（弹窗、确认删除、401 处理）。

### 5.8 留言管理（AdminMessages）

- 表格列：编号、署名、留言、时间、操作。
- 仅支持删除（二次确认），删除中按钮显示「销毁中…」。
- 空列表提示「留言簿尚空」。

## 6. 数据需求

### 6.1 实体与字段

| 表 | 字段 | 说明 |
|---|---|---|
| `users` | `id`、`username`、`password` | 后台账号；密码为 bcrypt 哈希；用户名唯一 |
| `projects` | `id`、`title`、`description`、`tech_stack`、`category` | `tech_stack` 逗号分隔；`category` 为 `CODE` / `HARDWARE` |
| `posts` | `id`、`date`、`title`、`summary` | 日期为字符串 `YYYY.MM.DD`，不做时区处理 |
| `messages` | `id`、`name`、`content`、`created_at` | 访客留言；`created_at` 默认当前时间 |
| `settings` | 见下表 | 单行配置；无记录时 GET 返回 `null`，PUT 时自动插入 |

### 6.2 `settings` 字段与前台消费情况

| 字段 | 用途 | 前台是否消费 |
|---|---|---|
| `name` / `title` / `tagline` / `email` | 基本登记 | 否（仅后台保存，前台 Hero 仍为静态文案） |
| `avatar` | 头像（链接或 Base64） | 否（前台 Hero 使用 `public/images/profile.jpg`） |
| `bio` | 个人简介 | 是（介绍页 AboutMeCard，优先于 monologue） |
| `age` / `location` / `major` / `hobbies` | 档案卡登记行 | 是 |
| `honors` | JSON 数组 `[{title, year}]` | 是 |
| `monologue` | 历史独白字段 | 仅作为 `bio` 为空时的回退 |
| `excerpt_text` / `excerpt_from` | 首页摘录卡 | 是（留空回退默认） |
| `reading_title` / `reading_author` / `reading_progress` | 首页在读卡 | 是（留空回退默认） |

## 9. 非功能需求

### 9.1 性能

- 轮播图片为压缩 JPEG（约 206–250KB / 张），`loading="lazy"`、`decoding="async"`、显式尺寸。
- 首页轮播的装饰全部为 CSS，无额外图片请求；字体走 Google Fonts CDN。
- 生产构建目标：JS < 350KB、CSS < 90KB（gzip 后约 105KB / 15KB）。

### 9.2 安全

- 后台写接口必须带 `Authorization: Bearer <JWT>`；JWT 有效期 7 天。
- 密码 bcrypt 哈希，不存明文。
- 所有 SQL 值使用参数化占位符；表名与字段名来自硬编码白名单。
- 访客留言前后端双重长度与非空校验；React 文本渲染避免 XSS。
- 已知风险（详见 TECH.md §10）：CORS 全开、无登录限流、JWT 存 localStorage、错误信息回传 SQL 细节。

### 9.3 可靠性

- 前端所有接口调用均有加载 / 失败状态；读取失败提示「请确认后端已在 3001 端口运行」。
- 数据库连接使用连接池（上限 10），避免频繁建连。
- 首页卡片与 AboutMeCard 在后端不可用时回退默认文本或显示 `—`，不白屏。

### 9.4 兼容性

- 目标浏览器：Chrome / Edge / Safari 最近两个大版本；移动端 iOS Safari、Android Chrome。
- 依赖 `backdrop-filter`、`clip-path`、CSS `aspect-ratio`、`mix-blend-mode`；不支持时降级为纯色底，不影响内容。
